# 数据源规范（Data Source Specification）

> 本文件定义财报诊断 Skill 的数据获取架构：内置数据源与路由、自定义数据源准入流程、数据回执机制与降级规则。
> 核心原则：**方法论不可替换，数据源可以替换**；任何数据源都只是「数据需求清单」的填空者。

## 1. 架构分层

```
方法论层（不可变）     七层诊断框架 + 指标字典（indicator-dictionary.md）
        │ 反推
契约层（固定格式）     数据需求清单（Data Requirement Manifest，A–E 五组字段）
        │ 路由
数据源层（可插拔）     内置源（scripts/：新浪/东财/巨潮/SEC EDGAR，开箱即用）
                      自定义源（用户声明 → 准入校验 → 优先采用）
                      手工自备（templates/ 双轨模板兜底）
        │ 产出
回执层（强制）         每个数值必须携带 {值, 报告期, 来源, 原始字段, 获取时间}
```

## 2. 数据源路由（优先级链与失败处置）

**优先级链**：用户自定义源（第 3 节 C1–C5 准入）> 内置数据源（scripts/）> 用户手工自备（templates/ 双轨模板）。

### 2.1 内置数据源调用方式

| 能力 | 脚本 | 用法示例 |
|---|---|---|
| A 股三表 + 公司资料（行业/简称/上市日期） | `scripts/fetch_a_share.py` | `python3 scripts/fetch_a_share.py 600519 [--years 5] [--out receipt.json]` |
| A 股治理数据（分红/股东户数/高管变动/质押粗筛/D14 股权融资推导） | `scripts/fetch_governance.py` | `python3 scripts/fetch_governance.py 600519` |
| 公告检索 + 年报 PDF 下载（D 组字段载体） | `scripts/fetch_announce.py` | `python3 scripts/fetch_announce.py 600519 --preset yearly --download` |
| 港股对照组三表 | `scripts/fetch_hk.py` | `python3 scripts/fetch_hk.py 00700.HK` |
| 美股对照组三表 + SEC EDGAR 官方校验 | `scripts/fetch_us.py` | `SEC_CONTACT=<邮箱> python3 scripts/fetch_us.py AAPL.O` |

环境要求：`python3 ≥ 3.8` + `requests`，无其他依赖。港美股代码须给全市场后缀与前导零（`00700.HK` / `AAPL.O`；.O=纳斯达克、.N=纽交所），脚本只校验格式不猜测。EDGAR 校验须配置 `SEC_CONTACT` 环境变量（SEC 合规要求 UA 实名），未配置自动跳过并在 warnings 注明。

### 2.2 失败全状态处置表（禁止自由发挥）

| 退出码 | 语义 | 典型情形 | 处置 |
|---|---|---|---|
| 0 | 成功 | items 可含 MISSING（数据不存在）/CONFLICT（双源超差） | 正常进入诊断；MISSING 按字典分层处置；CONFLICT 双值呈报不仲裁 |
| 3 | 参数错误 | 代码格式非法；北交所老号段（43/83/87/8 开头） | 核对代码；老号段 → 提示用户自备数据 |
| 4 | 接口故障 | 连接失败/5xx 重试耗尽/返回结构漂移 | 读 `errors[].action_hint`；稍后重试；持续失败 → 降级链（2.3） |
| 5 | 风控拒绝 | HTTP 403 | 换网络/降频/稍后重试（`scripts/selftest.md` 第 4 节被封对策） |

铁律：空 items 且 errors 为空 = 实现缺陷，**禁止以空冒充「无数据」**。

### 2.3 内置降级链

1. 公司资料：push2（主）→ CompanySurvey（备）——脚本内自动切换
2. A 股三表：新浪（主）+ 东财 F10（校验源自动交叉）；主源持续故障（exit 4）→ 提示用户自备
3. 美股：东财（主）+ EDGAR（校验，配置 SEC_CONTACT 后自动执行）
4. 全部内置路径失败 → 明确提示用户按 `templates/` 自备数据，经第 3 节准入后使用
5. 任何字段无法获取 → 回执标注 `MISSING`，禁止估算填充
6. 同行对照组数据不齐（遴选结果不足 2 家）→ 不终止分析，进入「无同行对比降级模式」：涉及同行对比的裁决改用「5 年趋势 + 绝对参照线」，报告标注降级模式；该模式下评级上限「可关注」（见 indicator-dictionary.md「评级聚合规则」章节）

## 3. 自定义数据源准入（对话声明 + 即时校验）

### 3.1 触发方式

用户在对话中以任何形式声明使用自己的数据源，例如：
- 「用我这份 Excel/CSV 里的财务数据」
- 「我们公司内部数据平台 / Wind / iFinD / Choice 的数据」
- 「调用我自己的 API / 数据库」

按 `templates/` 双轨模板提供的数据（`custom-source-template.csv` 或符合 `custom-source-schema.json` 的 JSON）→ 直接进入 C1–C5 校验，字段核对以 field_id 为准（field_id 对照 indicator-dictionary.md 数据需求清单编号，编号发布后冻结、不得复用或重排）。

一旦检测到此类声明，自定义源**优先于内置源**，但必须先通过准入校验，未通过前不得用于诊断结论。

### 3.2 准入校验清单（Agent 逐项执行）

| # | 校验项 | 通过标准 |
|---|---|---|
| C1 | 能力覆盖声明 | 明确该源能覆盖数据需求清单 A–E 中哪些组、缺哪些组；缺失组是否同意回落内置源补齐 |
| C2 | 口径合规 | 确认为合并报表口径；利润字段为归母净利润；能区分报告期；注明币种与单位（元/万元/亿元） |
| C3 | 字段完整性 | 对照数据需求清单逐组核对：A+B+C 组必需字段覆盖率 100% 为「完全通过」；核心字段（标 ▲ 项，见 3.4）缺失 → 不得通过 |
| C4 | 可溯源性 | 每个数值能标注来源（文件/接口/库表）与报告期；无法溯源的数值拒绝采用 |
| C5 | 样本抽验 | 随机抽 1–2 个科目（建议营业收入、经营现金流净额）与公开数据交叉核对，偏差须在舍入误差范围内；偏差异常 → 要求用户确认口径，否则拒绝 |

### 3.3 校验结果分级

| 等级 | 条件 | 处置 |
|---|---|---|
| ✅ 完全通过 | C1–C5 全部通过 | 全部采用自定义源 |
| ⚠️ 部分通过 | C3 中非核心字段缺失，且用户同意回落 | 缺失字段回落内置源补齐，回执中注明混合来源 |
| ❌ 不通过 | 核心字段缺失 / 口径不合规 / 不可溯源 / 抽验异常且未解决 | 拒绝采用，向用户说明具体原因与补齐路径，询问改用内置源还是补充数据 |

### 3.4 核心字段（▲ 不可缺失清单）

营业收入｜营业成本｜归母净利润｜净利润｜少数股东损益｜经营活动现金流净额｜销售商品提供劳务收到的现金｜总资产｜负债合计｜归母所有者权益｜货币资金｜短期借款｜长期借款｜应收账款｜存货｜商誉

> 核心字段支撑第 1/3/4 层的红灯级裁决，缺失会使诊断失去排雷能力，故不可妥协。其余字段缺失按「部分通过」降级处理。

## 4. 数据回执机制（防幻觉强制约束）

回执分两层，五要素（值/报告期/来源/原始字段/获取时间）贯通：

- **字段级回执（内置源脚本产出，stdout 统一 envelope）**：`items[]`（field_id/value/period/source/raw_field/retrieved_at/unit/currency/status/note）+ `conflicts[]`（双源超差的完整双值记录）+ `errors[]`（endpoint/http_status/message/action_hint）+ `meta`（field_coverage/warnings）；`status ∈ OK | MISSING | CONFLICT`
- **指标级回执（Agent 计算后产出）**：

```json
{
  "indicator": "S4-01",            // 指标字典 ID
  "value": 1.18,                   // 计算结果
  "period": "2025-FY",             // 报告期
  "source": "内置源 fetch_a_share.py/sina_lrb",   // 来源（含自定义源标识）
  "raw_fields": {"C01": ..., "B01": ...},  // 原始字段值（溯字段级回执）
  "retrieved_at": "2026-10-15"     // 获取时间
}
```

纪律：
- 无回执的数值**禁止**进入指标计算与诊断结论
- 取不到的字段标注 `MISSING`，禁止估算、禁止编造
- 职责边界：脚本只产出**字段级** MISSING/CONFLICT 事实；指标级「无法计算」与评级级降档/「数据不足，暂不定级」由 Agent 按 indicator-dictionary.md「通用口径 - MISSING 分层处置」裁决，脚本不越权
- D 组公告类字段由 Agent 阅读 PDF 提取后自行生成回执（来源=公告 PDF 文件名+页码）
- 诊断报告的关键指标表格中必须可回溯来源（报告中以来源标注列或脚注呈现）

## 5. 合规声明与数据源分级

- 本 Skill 只分发代码与方法，**不分发、不转售任何市场数据**；数据由使用者按各数据源条款自行获取并承担合规责任
- 全部代码自研；接口 URL/参数为公开事实信息（接口调研参考致谢见 README.md）
- 自定义源若涉及授权终端数据（Wind/iFinD 等），使用者须确保其使用范围符合授权协议

内置源合规分级：

| 级 | 源 | 依据与约束 |
|---|---|---|
| S（官方监管披露） | SEC EDGAR、巨潮资讯 | 官方公开披露平台；EDGAR 须 UA 实名（SEC_CONTACT）且限速 ≤8 req/s（脚本内置） |
| B（持牌信息商公开页面接口） | 新浪财经、东方财富（push2/datacenter/emweb） | 面向公众的免费页面接口；仅限个人研究用途、低频串行访问（脚本内置限流）；禁止并发轰炸与数据转售；存在风控可能（对策见 `scripts/selftest.md` 第 4 节） |
| C（推导/衍生） | D14 现金流口径推导、CSDC 质押粗筛 | 标注推导口径与局限，不作为裁决唯一依据 |

## 6. 同行对照组遴选规范

1. **优先级**：用户指定对照组 > 自动遴选。用户指定时直接使用，并在报告中标注「用户指定」。
2. **自动遴选规则**：同一行业分类口径下的二级行业（内置源=东财行业分类；用户自定义源按其可得口径，报告标注所用口径），按**营业收入规模最接近**取 2–3 家；剔除 ST/*ST、上市不足 3 年、金融业（银行/保险/券商/多元金融）公司。G0-05 闸口与同行遴选必须使用同一口径保证自洽（FR-15-2）。
3. **可复现要求**：对照组名单、遴选依据（行业分类口径、规模数值）必须写入报告来源标注，保证同一输入可复现同一对照组。
4. **降级衔接**：自动遴选结果不足 2 家 → 触发本规范第 2.3 节规则 6 的「无同行对比降级模式」。
