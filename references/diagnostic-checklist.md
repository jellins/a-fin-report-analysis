# A 股财报诊断清单（终版 v2）

- 方法论来源：唐朝《手把手教你读财报（新准则升级版，2021）》框架的蒸馏重构，经两轮独立专家评审
- 性质：方法论清单，不含原书原文复述；标注〔经验值〕的阈值为市场经验参照，非原书明示数字
- 输出边界：本清单输出**企业质地判断（排雷 + 识好）**，不含估值与买卖时点判断

**总则（凌驾于一切单条规则之上）**
1. 任何指标的裁决必须落在两个维度上：**自身连续 5 年以上趋势 + 同行业 2–3 家对比**。单年快照只用于初筛，不用于定性。
2. 全部指标基于**合并报表**与**归属于母公司股东的净利润（归母净利润）**口径计算。
3. 任一指标亮红灯 → **下钻财报附注**（应收账龄、存货构成、商誉对应标的、关联交易、或有事项）→ 再裁决。附注下钻是决策流的标准回路，不是可选项。

---

## 第 0 层 前置闸口（任一不过，终止分析）

> 执行顺序：行业适用性（0.5）与风险警示（0.6）优先执行；执行语义以指标字典第 0 层（G0-01～G0-06）为准。

| # | 检查项 | 排除标准 |
|---|---|---|
| 0.5 | 行业适用性（优先执行） | 银行/保险/券商/多元金融 → 终止诊断：金融企业报表结构与指标体系完全不同（资本充足率/不良率/拨备覆盖率等），本框架强行套用会产生系统性误判，建议使用金融专用分析框架 |
| 0.6 | 风险警示状态 | 当前处于 ST/*ST/退市整理期 → 直接排除 |
| 0.1 | 审计意见类型 | 近 5 个年度报告期出现非"标准无保留意见"（保留/否定/无法表示意见）→ 直接排除，更早年度不追溯；带强调事项段的无保留意见 → 通过但记预警，须阅读强调事项内容并写入报告 |
| 0.2 | 报表口径 | 只看合并报表，母公司报表会系统性扭曲判断 |
| 0.3 | 上市年限 | 上市未满 3–5 年 → 排除或显著降权（上市前业绩粉饰动机强，未经完整周期检验）；借壳/重大资产重组上市公司按重组完成日起算，无法核验借壳史时标注「未核验借壳史」 |
| 0.4 | 数据跨度 | 取连续 ≥5 年年报 + 同行对照组，禁止单年判断；仅对照组不齐 → 不终止，进入「无同行对比降级模式」，评级上限「可关注」 |

## 第 1 层 安全性（能不能活）

> 阈值为初筛，裁决靠趋势 + 同行对比。

| # | 指标 | 健康标准 | 危险信号 |
|---|---|---|---|
| 1.1 | 现金及现金等价物 vs 有息负债 | 现金 ≥ 有息负债（极端生存底线） | 覆盖不了 → 债务生死线失守 |
| 1.2 | 有息负债 ÷ 总资产 | 越低越好 | >60%〔经验值，原书口径为"格外小心"〕→ 高危线，原则上回避，特例逐债分析 |
| 1.3 | 存贷双高检查 | 货币资金与有息负债不同时高企；利息收入与存款规模匹配 | 双高 + 利息收入明显偏低 → 货币资金造假嫌疑（康得新/康美式爆雷前兆），排除 |
| 1.4 | 流动比率 / 速动比率（辅助） | 参照约 2 / 约 1，行业差异大 | 持续恶化或显著低于同行 → 预警 |
| 1.5 | 利息保障倍数（辅助） | 息税前利润/利息费用，倍数高且稳 | 逼近 1 或持续下滑 → 预警 |

## 第 2 层 资产质量（家底真不真）

> 阈值为初筛，裁决靠趋势 + 同行对比。

| # | 检查项 | 判断标准 |
|---|---|---|
| 2.1 | 应收类资产合计（应收账款 + 应收票据 + 应收款项融资 + 合同资产）÷ 总资产 | >30%〔经验值〕高度警惕；应收增速持续 > 营收增速 → 红色警报（靠放账期堆收入） |
| 2.2 | 应收票据结构 | 银行承兑汇票近似现金；**商业承兑汇票视同应收账款从严看待**，商票占比高 → 应收质量打折 |
| 2.3 | 坏账计提政策 | 与同行对比，计提显著宽松 → 利润粉饰嫌疑 |
| 2.4 | 存货周转率趋势 × 毛利率趋势 | 周转降 + 毛利率升（逻辑矛盾）→ 靠加大生产摊薄固定成本的造假嫌疑；生鲜/消费电子/快时尚行业存货 = 定时炸弹，高端白酒等例外 |
| 2.5 | 在建工程 | 长期不转固 + 持续追加投资 → 规避折旧美化利润 / 资金通道嫌疑 |
| 2.6 | 商誉 ÷ 净资产 | 必须看相对规模：>30%〔经验值，非原书明示阈值〕高危；**业绩承诺到期后首年**重点盯减值（商誉只测减值不摊销，时点选择权在管理层） |
| 2.7 | 长期待摊费用 | 金额大 → 已花掉的钱包装成资产，资产质量打折 |
| 2.8 | 其他应收款 / 预付账款 | 其他应收款巨大（财报垃圾筐）→ 关联方资金占用嫌疑；预付挂账超 1 年 → 资金通道嫌疑 |
| 2.9 | 投资性房地产计量模式 | 公允价值模式下增值直接进利润且无需真实交易 → 合法美化通道；增值占利润比高 → 剔除后重估 |
| 2.10 | 非主业资产占比 | 大量理财、跨界股权投资 → 管理层用资金投票，主业见顶信号 |
| 2.11 | 合同负债 + 应付账款/票据（正向指标） | 合同负债持续增长 = 先款后货、产品抢手；大额无息应付款 = 无偿占用上游资金。两者共同构成产业链话语权的财务证据 |
| 2.12 | 递延所得税资产/负债 | 规模异常变动 → 利润调节旁证 |

## 第 3 层 盈利质量（赚的是不是真钱）

> 阈值为初筛，裁决靠趋势 + 同行对比。利润类指标一律用**归母净利润**。

| # | 指标 | 判断标准 |
|---|---|---|
| 3.1 | 毛利率 | 稳定 >40%〔经验值〕多有护城河；<20% 红海回避；**同行对比优先于绝对阈值**；无独家技术/品牌支撑却显著高于同行 → 造假嫌疑 |
| 3.2 | 费用率 =（销售 + 管理 + 财务费用）÷ 毛利润 | <30% 优秀；30%–70% 正常；>70%〔经验值〕无长期价值。财务费用为负（净利息收入）时可剔除后计算 |
| 3.3 | 研发投入 | 辩证看待，不迷信"高研发=高成长"；**资本化率显著高于同行 → 当期利润美化 + 未来摊销/减值双雷**；高投入无商业化落地 → 回避 |
| 3.4 | 主业成色（新准则口径，关键修正） | 新准则下政府补助进"其他收益"、处置资产进"资产处置收益"，均在**营业利润之内**。因此除营业利润/利润总额外，必须单独检查：**（其他收益 + 资产处置收益 + 投资收益）÷ 营业利润**，占比高 → 主业成色存疑，靠杂项撑门面 |
| 3.5 | 少数股东损益 | 少数股东损益占净利润比例异常高 → 利润被分走，上市公司股东喝汤；全部盈利指标改用归母口径复核 |
| 3.6 | 其他综合收益（OCI） | 净利润与综合收益总额背离巨大 → 利润表外的盈亏暗流（新金融工具准则下大量公允价值变动走 OCI） |
| 3.7 | 折旧摊销政策 | 折旧年限显著长于同行 / 残值率显著偏高 → 利润美化 |

## 第 4 层 现金验证（利润有没有人买单）

> 阈值为初筛，裁决靠趋势 + 同行对比。

| # | 指标 | 判断标准 |
|---|---|---|
| 4.1 | 营收含金量 = 销售商品、提供劳务收到的现金 ÷ 营业收入 | 持续 ≥1（理论值 = 1+主业增值税率：货物约 1.13 / 建筑、交通、农产品约 1.09 / 现代服务约 1.06；出口占比高者下移；混合收入按收入占比最大业务取档）→ 收入有现金支撑；长期 <1 → 收入真实性质疑 |
| 4.2 | 利润含金量 = 经营现金流净额 ÷ 净利润（归母） | **长期累计** ≥1 → 真利润；长期 <0.5 或为负 → 纸面富贵 |
| 4.3 | 经营现金流净额 | 必须长期为正，是自我造血能力的底线 |
| 4.4 | 自由现金流 = 经营现金流净额 − 购建固定资产、无形资产和其他长期资产支付的现金 | 长期为正 → 扩张不耗血；同时用购建支出验证投资活动的真实性 |
| 4.5 | 投资现金流方向 | 为负且投向主业能力圈 → 正常扩张；长期为正 → 收缩/衰退；频繁跨界 → 多元恶化预警 |
| 4.6 | 现金流肖像（8 类完整版，见下表） | 连续 5 年逐年分类取**主导型**定性（并列取差：奶牛 > 老母鸡 > 蛮牛 > 妖精 > 排除类）；主导型为排除类 → 否决级红灯；5 年内 ≥2 年排除类 → 风险级红灯；仅最新 1 年 → 预警 + 下钻；事件扰动注明不剔除。执行语义以指标字典 S4-06 多期判定规则为准 |
| 4.7 | 分红检验 | 经营现金流为正 + 持续高分红 → 利润真实性最强佐证（能分出去的钱才是真的）；累计融资多、分红少 → 把市场当提款机 |

**现金流肖像 8 类**（顺序：经营 / 投资 / 筹资）

| 组合 | 类型 | 含义与处置 |
|---|---|---|
| + − − | 奶牛型 | 主业造血、对内扩张、分红/还债回报股东 → **最优** |
| + − + | 蛮牛型 | 赚的钱 + 筹的钱全部砸扩张 → 高风险高关注：项目可靠性 + 资金链紧绷度是裁决点，扩张失败即沦为赌徒 |
| + + − | 老母鸡型 | 经营赚钱、不再扩张、收回投资 + 分红还债 → 成熟期现金牛；对成长投资者是主业见顶信号 |
| + + + | 妖精型 | 三面来钱，去向不明 → 要么酝酿超大项目，要么圈钱，高度警惕 |
| − + + | 骗吃骗喝型 | 主业不赚钱，靠卖家当 + 借钱维持 → 排除 |
| − + − | 混吃等死型 | 主业不赚钱，靠卖家当还债/分红 → 排除 |
| − − + | 赌徒型 | 经营不赚钱、烧钱扩张、全靠融资续命 → 排除（融资环境收紧即断裂） |
| − − − | 大出血型 | 三口全在流血 → 直接排除 |

## 第 5 层 管理层与治理（人靠不靠谱）

| # | 信号 | 判断 |
|---|---|---|
| 5.1 | 大股东股权质押比例 | >70%〔经验值，非原书明示〕→ 资金链紧张 + 侵占动机 + 平仓螺旋风险，红线 |
| 5.2 | 大股东减持 | 无合理理由持续大额减持 → 内部人用脚投票 |
| 5.3 | 会计师事务所 / 财务总监变动 | 频繁更换（尤其年报披露前换所）→ 审计方不愿背书的重大风险信号 |
| 5.4 | 会计政策风格 | 计提严格、研发费用化为主、披露坦诚 → 管理层品性加分；反之减分 |
| 5.5 | 关联交易占比 | 高 → 利益输送温床 |
| 5.6 | 表外或有事项 | 对外担保（尤其对非并表关联方）、重大未决诉讼、承诺事项 → 正文看不见的负债，附注必查 |
| 5.7 | 高危行业加审 | 农林牧渔、生物科技等生物资产难盘点行业 → 执行更严标准 |

## 第 6 层 综合判定（好生意长什么样）

| # | 工具 | 用法 |
|---|---|---|
| 6.1 | ROE（归母口径）+ 杜邦三模式 | 连续多年 ROE ≥15%〔经验值，源自作者选股体系〕入候选池；拆解来源：高毛利（茅台模式）> 高周转（沃尔玛模式）> 高杠杆（银行模式），判断可持续性 |
| 6.2 | 管理层能力：周转率家族 | 应收 / 存货 / 固定资产 / 总资产周转率，**只做同行横向对比**；营收暴增但周转率恶化 → 增长真实性存疑 |
| 6.3 | 成长性指标组 | 营收增长率、归母净利润增长率、总资产/净资产增长率；成长必须有现金流与资产质量配合，"无现金成长的成长"是陷阱 |
| 6.4 | 自洽性总检 | 营收、利润、现金流、应收、存货、周转率六者必须互相印证；任何单指标独走，找到解释前不做结论 |

## 使用声明

1. 本清单输出企业质地判断（排雷 + 识好），**不构成买卖建议**；估值与买卖时点不在本清单范围。
2. 所有标注〔经验值〕的阈值是快速初筛的代理指标，最终裁决必须落到"自身 5 年趋势 + 同行对比"。
3. 亮红灯指标的标准后续动作是附注下钻（应收账龄、存货构成、商誉标的、关联交易、或有事项）。
4. 财务分析对象是合并报表，利润类指标使用归母净利润口径。
5. 评级聚合（四档质地评级）以 `indicator-dictionary.md`「评级聚合规则」章节为唯一准绳；本清单不提供第二套聚合口径。
