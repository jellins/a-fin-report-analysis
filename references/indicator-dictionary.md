# 指标字典（Indicator Dictionary）

> 本文件是财报诊断的**唯一指标来源**。执行诊断时只允许使用本字典中的指标、公式与裁决规则，禁止自创指标、禁止修改公式、禁止脱离口径计算。
> 每个指标包含：ID / 定义 / 公式 / 口径 / 所需原始字段 / 参照线 / 裁决规则。
> 标注〔经验值〕的阈值为初筛代理指标，最终裁决必须落到「自身连续 ≥5 期趋势 + 同行业 2–3 家对比」。

## 通用口径（适用于全部指标）

- 报表口径：合并报表，禁止使用母公司报表数据
- 利润口径：归属于母公司股东的净利润（归母净利润）
- 平均值的定义：（期初 + 期末）÷ 2
- 趋势口径：连续 ≥5 个年度报告期； interim 报告仅作参考，不作定性依据
- 单位与币种：必须在数据回执中注明，跨币种对比先统一折算

### MISSING 分层处置（数据缺失时的固定规则）

- 字段级：取不到的字段在回执中标注 `MISSING`，禁止估算、禁止编造。
- 指标级：某指标所需字段 MISSING → 该指标状态记为「无法计算」，不参与红灯/预警/加分任何计数。
- 评级级：▲核心字段缺失导致任一否决级指标无法计算 → 输出「数据不足，暂不定级」；非否决级指标「无法计算」≥3 个 → 评级降一档；无法计算指标清单必须列入诊断报告。

## 第 0 层 前置闸口（Gate Checks，非数值指标，任一不过则终止）

> 执行顺序：**G0-05 行业适用性与 G0-06 风险警示优先于 G0-01～G0-04 执行**（行业判定决定后续指标与豁免的适用性）。

| ID | 检查项 | 通过条件 | 所需数据 |
|---|---|---|---|
| G0-05 | 行业适用性（优先执行） | 非银行/保险/券商/多元金融行业；金融业 → 终止诊断并输出标准说明：「金融企业报表结构与指标体系完全不同（资本充足率/不良率/拨备覆盖率等），本框架强行套用会产生系统性误判，建议使用金融专用分析框架」 | 行业分类以数据源可得口径为准（内置源=东财行业分类）并在回执标注口径；数据源无行业字段时询问用户判定；识别结果写入回执 |
| G0-06 | 风险警示状态 | 当前非 ST/*ST/退市整理期；命中 → 直接排除 | 公司最新状态（行情/公告） |
| G0-01 | 审计意见类型 | 近 5 个年度报告期全部为「标准无保留意见」，更早年度不追溯；带强调事项段的无保留意见 → 通过但记预警，须阅读强调事项内容并写入报告 | 各年度审计意见（年报/公告，D01） |
| G0-02 | 报表口径 | 数据源确认为合并报表 | 数据源元信息 |
| G0-03 | 上市年限 | 上市满 3–5 年，否则降权并在结论中明示；借壳/重大资产重组上市公司按重组完成日起算；无法核验借壳史时按上市日期起算并在报告中标注「未核验借壳史」 | 上市日期（D09，含重组完成日） |
| G0-04 | 数据完备性 | 本公司连续 ≥5 期三表齐备为硬条件（不齐则终止）；仅同行对照组不齐 → 进入「无同行对比降级模式」（裁决改用 5 年趋势 + 绝对参照线，报告标注降级，评级上限「可关注」，见评级聚合规则章节） | 数据需求清单覆盖检查 |

## 第 1 层 安全性

| ID | 指标 | 公式 | 参照线 | 裁决规则 | 红灯分级 |
|---|---|---|---|---|---|
| S1-01 | 现金覆盖有息负债 | 现金及现金等价物 ÷ 有息负债* | ≥1 | <1 → 红灯（债务生死线失守） | 风险级 |
| S1-02 | 有息负债率 | 有息负债 ÷ 总资产 | >60%〔经验值〕为高危 | 超线 → 原则上回避，特例须逐债分析并在报告中说明 | 风险级 |
| S1-03 | 存贷双高 | 货币资金÷总资产 与 有息负债÷总资产 同时高企；辅以 利息收入÷平均货币资金 | 利息收入/货币资金显著低于同期存款利率 | 双高 + 利息收入异常偏低 → 红灯（货币资金造假嫌疑，可直接排除） | 否决级 |
| S1-04 | 流动比率 / 速动比率 | 流动资产÷流动负债；(流动资产−存货)÷流动负债 | 参照约 2 / 约 1 | 仅作辅助预警：持续恶化或显著低于同行 → 预警 | — |
| S1-05 | 利息保障倍数 | 息税前利润（利润总额+利息费用）÷ 利息费用 | 越高越好 | 逼近 1 或持续下滑 → 预警 | — |

*有息负债 = 短期借款 + 一年内到期的非流动负债 + 长期借款 + 应付债券 + 租赁负债（新租赁准则）

## 第 4 层 现金验证

| ID | 指标 | 公式 | 参照线 | 裁决规则 | 红灯分级 |
|---|---|---|---|---|---|
| S4-01 | 营收含金量 | 销售商品、提供劳务收到的现金 ÷ 营业收入 | 持续 ≥1；理论值 = 1 + 主业增值税率：货物 13%→约 1.13｜建筑/交通/农产品 9%→约 1.09｜现代服务 6%→约 1.06；出口占比高者参照线下移并注明；混合收入按收入占比最大业务取档并在报告中注明 | 长期 <1 → 红灯（收入真实性质疑）；介于 1 与参照线之间 → 结合 S2-01/S2-02 应收趋势裁决 | 否决级 |
| S4-02 | 利润含金量 | 经营活动现金流净额 ÷ 归母净利润 | 长期累计 ≥1 | 长期 <0.5 或为负 → 红灯（纸面富贵） | 否决级 |
| S4-03 | 经营现金流净额 | 直接取值 | 长期为正 | 常年为负 → 红灯 | 否决级 |
| S4-04 | 自由现金流 | 经营现金流净额 − 购建固定资产、无形资产和其他长期资产支付的现金 | 长期为正 | 长期为负 → 预警（扩张耗血） | — |
| S4-05 | 投资现金流方向 | 投资活动现金流净额符号 + 投向 | 为负且投向主业能力圈 | 长期为正 → 预警（收缩/衰退）；频繁跨界 → 红灯（多元恶化） | 风险级 |
| S4-06 | 现金流肖像 | （经营, 投资, 筹资）符号八分类（连续 5 年逐年判定） | 见下表 | 按多期判定五条规则定性（见表下说明） | 否决级（排除类主导型） |
| S4-07 | 分红检验 | 分红率 = 当年分红 ÷ 归母净利润；分红融资比 = 累计分红 ÷ 累计融资 | 持续分红 | 经营现金流为正 + 持续高分红 → 利润真实性最强佐证；融资多分红少 → 预警（提款机特征） | — |

**S4-06 现金流肖像分类表**（顺序：经营 / 投资 / 筹资）

| 组合 | 类型 | 定性 |
|---|---|---|
| + − − | 奶牛型 | 最优：主业造血、对内扩张、回报股东 |
| + − + | 蛮牛型 | 高风险高关注：裁决点为项目可靠性与资金链紧绷度 |
| + + − | 老母鸡型 | 成熟期现金牛；成长视角下为主业见顶信号 |
| + + + | 妖精型 | 三面来钱去向不明，警惕圈钱 |
| − + + | 骗吃骗喝型 | 排除 |
| − + − | 混吃等死型 | 排除 |
| − − + | 赌徒型 | 排除（融资收紧即断裂） |
| − − − | 大出血型 | 直接排除 |

**S4-06 多期判定规则（替代单年定性，与总则「禁止单年数据定性」对齐）**

1. **逐年分类**：连续 5 个年度各自按（经营/投资/筹资）符号八分类，序列全量呈现于报告。
2. **主导型**：5 年中出现频次最高的类型为定性标签；频次并列时取较差者，优劣序固定为：奶牛 > 老母鸡 > 蛮牛 > 妖精 > 排除类四型。
3. **最新年校验**：最新年度优于主导型 → 标「边际改善」；劣于主导型 → 标「边际恶化」并触发当年大额现金事件下钻。
4. **红灯分级**：主导型为排除类四型 → 否决级红灯；主导型非排除类但 5 年内 ≥2 年落入排除类 → 风险级红灯；仅最新 1 年为排除类且此前健康 → 预警 + 下钻当年事件，不定红灯。
5. **事件扰动**：某年符号由一次性事件（定增/大额并购/出售资产）造成时，报告注明「事件驱动型波动」作裁决参考，但**不从序列中剔除**——剔除权不交 Agent。

## 评级聚合规则（Rating Aggregation，四档评级的唯一裁决依据）

> 本章节是四档质地评级的**唯一裁决规则**。Agent 只允许按本章节机械裁决，禁止自由裁量聚合。
> 计数闭合校验：否决级 12 项 + 风险级 13 项 + 无红灯 23 项 = 48 项指标。

### 1. 四档门槛

| 评级 | 机械裁决条件 |
|---|---|
| 直接排除 | ① G0 任一闸口不过；或 ② 任一否决级红灯（经 D 组附注下钻后嫌疑仍未排除） |
| 高风险回避 | 风险级红灯 ≥1；或预警 ≥3（S5-07 高危行业 ≥2） |
| 优质候选 | 无任何红灯 + 预警 ≤1（高危行业为 0）+ 三硬条件同时满足（S6-01 ROE 连续多年 ≥15%〔经验值〕；S4-06 主导型为奶牛/老母鸡；S4-02 利润含金量长期累计 ≥1）+ 加分项 ≥1（S2-14 / S2-15 / S4-07） |
| 可关注 | 不满足以上三档的其余情形 |

### 2. 裁决顺序总则

按固定顺序机械裁决：① 按四档门槛初步定档 → ② 应用降档规则（非否决级指标「无法计算」≥3 个 → 降一档） → ③ 应用评级上限裁剪（未盈利企业 / 无同行对比降级模式，上限「可关注」；多个上限同时触发时取最严） → ④ 附加评级状态标注（暂定 / 数据不足）。

### 3. 预警计数口径

「预警」全集 = 全部指标级预警 + 全部闸口级预警（含 G0-01 强调事项段预警、S4-06 边际恶化及单年排除类预警），逐条列入评级依据摘要。

### 4. 保护规则

- 附注下钻后仍「待验证」的嫌疑项 ≥1 → 评级标注「暂定」，数据补齐后复核。
- ▲核心字段缺失导致任一否决级指标无法计算 → 输出「数据不足，暂不定级」，不强行给档。
- 「暂定」「数据不足」等评级状态统一为状态标注，可多值并列呈现（如「可关注（暂定）」）。

### 5. 评级依据摘要（报告必含）

固定字段：红灯清单（指标 ID + 分级）｜预警清单（指标 ID + 原因）｜三硬条件命中情况｜加分项命中情况｜降档与上限适用记录｜状态标注。
