# 自定义数据源接入指引（templates/）

把你的数据对接到本 Skill，只有两步：**按模板填空 → 在对话中声明使用**。本目录提供双轨模板，任选其一。

## 1. 两种接入方式选择

| 你的数据形态 | 使用模板 | 说明 |
|---|---|---|
| 手工整理 / Excel / Wind、iFinD、Choice 导出 | `custom-source-template.csv` | 长表格式，一行一条「公司-报告期-字段」，直接按列填写 |
| 内部 API / 数据库 / 程序化提取 | `custom-source-schema.json` | 按 Schema 输出 JSON（`meta` 口径声明 + `records` 记录数组），可被程序预校验 |

填写完成后，在对话中声明（如「用我这份按模板整理的数据诊断 XX 公司」），Agent 将直接进入 C1–C5 准入校验，字段核对以 `field_id` 为准，无需现场对齐字段名。

## 2. 字段映射表（field_id ↔ 中文字段名 ↔ 常见数据源列名）

> ▲ = 核心字段（16 项，C3 校验一票否决）。多数科目在 Wind/同花顺/东财的列名与中文字段名一致；不一致时按科目含义对齐，**禁止用近似科目替代**（如以"营业利润"替代"利润总额"）。

## 3. C1–C5 用户侧自查表（提交前自检，加速准入）

| # | 校验项 | 自查要点 |
|---|---|---|
| C1 | 能力覆盖 | 声明覆盖哪些组、缺哪些组；缺失组是否同意回落内置源补齐 |
| C2 | 口径合规 | 合并报表 ✔ 归母净利润 ✔ 报告期可区分 ✔ 单位币种已注明 ✔ |
| C3 | 字段完整性 | ▲16 项核心字段 100% 覆盖；A+B+C 组尽量全覆盖 |
| C4 | 可溯源 | 每条记录 source_note 已填 |
| C5 | 样本抽验 | 准备 1–2 个科目（建议 B01 营业收入、C02 经营现金流净额）可与公开数据对齐 |

## 4. D 组缺失时的混合模式建议

D 组（附注与治理）是最难自备的一组。D 组缺失不阻断主流程，但红灯下钻会标注「待验证」并使评级带「暂定」状态。**建议**：D 组同意回落内置源（`scripts/fetch_announce.py` 巨潮公告层 + `scripts/fetch_governance.py` 治理数据）补齐，走「⚠️ 部分通过」混合模式——这是设计上预留的最实用路径。
